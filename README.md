# 手机备份工具 (PhoneBackup)

一个原生安卓 App，把手机里的**照片、视频、音频和其他文件**备份到：

1. **USB 移动硬盘 / U 盘**（OTG 连接，通过系统目录授权写入）
2. **网络共享 SMB / NAS / Windows 共享文件夹**（局域网备份）

## 功能特性

- 备份内容可选：图片 / 视频 / 音频 / 其他文件（下载、文档目录）
- **增量备份**：已存在且未变化的文件自动跳过，不重复传输
- 保留原始文件夹结构
- 前台服务 + 通知栏进度，备份过程不被系统杀掉，可随时取消
- 单文件失败不中断整体，结束后汇总成功 / 跳过 / 失败数量
- 写入校验（大小一致），本地写入采用临时文件 + 改名 + fsync，防止断电产生坏文件
- SMB 支持 SMB2/3，支持匿名或账号密码登录，可先"测试连接"

## 使用方法

### USB 移动硬盘
1. 用 OTG 线把移动硬盘接到手机，系统提示时允许访问。
2. 打开 App，目标选"USB 移动硬盘 / U 盘"，点"选择硬盘上的备份目录…"。
3. 在系统文件选择器里进入移动硬盘，选一个目录（可选硬盘根目录或新建文件夹），点"使用此文件夹"并授权。
4. 勾选要备份的内容，点"开始备份"。

> 为什么用目录选择器：现代安卓（6.0+）不允许普通 App 直接用路径写入可移动 USB 存储，
> 必须通过系统的存储访问框架（SAF）授权，这是唯一稳定可靠的方式。授权一次后会持久保存。

### 网络共享 (SMB)
1. 目标选"网络共享 (SMB / NAS)"，点"配置网络共享…"。
2. 填写：服务器地址（IP）、共享名、子文件夹（可选）、域/工作组（可选）、用户名、密码。
3. 点"测试连接"确认成功后保存。
4. 回到主界面勾选内容，点"开始备份"。

## 已处理的边界情况（查漏补缺）

- 目标目录不存在 / 不可写 / 授权失效 → 明确报错提示
- 本地目标空间不足 → 备份前预检并提示需要/剩余空间
- 文件中途断开 → 本地用临时文件+改名，不会产生半截坏文件
- 写入字节数与源不一致 → 判定失败并回滚
- 单个文件读取/写入失败 → 记录错误后继续，不影响其他文件
- 用户取消 → 优雅停止并提示
- 权限被拒 → 提示需要存储权限
- 分区存储（Android 10+）→ 用 MediaStore 查询媒体与下载/文档文件，返回 content:// URI 正常读取
- SAF 无法设置修改时间 → 增量判断改为"存在+大小一致"，避免每次全量重传
- 文件名含路径分隔符 → 清洗，防止越权写到目标目录之外
- 通知权限（Android 13+）→ 单独申请，被拒也不影响备份本身

## 构建

用 Android Studio 打开本目录，或命令行：

```
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

- minSdk 26（Android 8.0），targetSdk 34
- 需要 JDK 17+，AGP 8.2.2，Gradle 8.4

## 依赖

- AndroidX (appcompat / activity / documentfile / localbroadcastmanager / material)
- jcifs-ng 2.1.10（SMB 客户端，支持 SMB2/3）

## 安全说明

SMB 密码以明文保存在应用私有 SharedPreferences 中，仅适合个人设备。
如需更高安全性，可改用 Android Keystore 对密码加密后再存储。
